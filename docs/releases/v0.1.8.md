## CodexBridge Weixin Admin v0.1.8

### Highlights

- Modularized the Weixin admin console browser code and added real browser interaction smoke coverage.
- Hardened long-running Web replies with idle timeouts, bounded output, process-tree cleanup, and strict server/client type gates.
- Reduced Codex AppClient protocol duplication by sharing event mapping, output artifacts, error handling, and turn completion policies.
- Split thread, instructions, model, plugin, app, MCP, automation, approval, and permission decisions out of BridgeCoordinator.
- Enabled the Electron ASAR runtime boundary to reduce packaged source sprawl while keeping the external service runtime functional.
- Added automated dependency update proposals and updated Codex CLI, Electron, tsx, and Zod patch versions.
- Fixed source-workspace Electron startup so desktop shortcuts resolve the service runner, preload, and application resources from the repository root.

### Installation

Download and run:

`CodexBridge-Weixin-Admin-Setup-0.1.8.exe`

Existing installations can use the in-app update flow after the release assets are available.

### Notes

- Back up important CodexBridge state and account data before upgrading.
- Close CodexBridge Weixin Admin before running the installer.
- Telegram runtime integration is not included in this release.
