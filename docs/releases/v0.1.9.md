## CodexBridge Weixin Admin v0.1.9

### Highlights

- Extracted Assistant Record command routing, draft handling, presentation, and persistence orchestration into focused services while preserving scope isolation, confirmation ordering, uploads, and thread binding.
- Split Weixin admin backup, diagnostics, log maintenance, and route resolution out of the main server, with bounded diagnostics, sanitized failures, transactional rollback, and pre-mutation import validation.
- Hardened backup imports so provider, session, binding, settings, metadata, account, and account-selection references must resolve against the effective existing-plus-imported state before anything is changed.
- Added strict TypeScript boundaries for command services and Weixin admin services, and kept the full release pipeline type-safe across root and package builds.
- Shared Codex approval state and normalized turn-lifecycle decisions between the root and Native API AppClients while preserving numeric request IDs, approval ordering, terminal output/media selection, timeout behavior, and cleanup.
- Removed the legacy Web chat console and retained the focused desktop Weixin admin experience.
- Updated Electron to 41.10.6, `@testing-library/user-event` to 14.6.6, and `@openai/codex` to 0.149.0; the production dependency audit reports no high-severity vulnerabilities.

### Installation

Download and run:

`CodexBridge-Weixin-Admin-Setup-0.1.9.exe`

Existing installations can use the in-app update flow after the release assets are available.

### Notes

- Back up important CodexBridge state and account data before upgrading.
- Close CodexBridge Weixin Admin before running the installer.
- Telegram runtime integration is not included in this release.
