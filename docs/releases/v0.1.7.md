## CodexBridge Weixin Admin v0.1.7

### Highlights

- Added update verification and installation history with corrupt-state recovery.
- Added trusted Ed25519 public-key rotation with multi-key support.
- Added Web console typecheck and production build verification to CI and release gates.
- Updated the Web console documentation for the current sessions, replies, settings, automations, and runtime views.
- Hardened long-running turn recovery, durable delivery checkpoints, and failed-delivery recovery.
- Improved provider and model catalog validation for account-level defaults.
- Extracted command catalog, help rendering, and plugin search text algorithms into focused core modules.
- Added focused regression tests for the new security, release, recovery, and extraction boundaries.

### Installation

Download and run:

`CodexBridge-Weixin-Admin-Setup-0.1.7.exe`

Existing installations can use the in-app update flow after the release assets are available.

### Notes

- Telegram runtime integration is not included in this release.
- Keep existing CodexBridge state and account data backed up before upgrading.
